# Kihon images

The pictures in this folder are geometric line drawings (`<id>.svg`), generated by `tools/draw_kihon.py` in the project root. To change a pose, edit its entry in `POSES` in that script and run `python tools/draw_kihon.py`. `data/kihon.json` points each technique at its `.svg`.

Want to use a photo or other picture instead? Put it here and set `"image"` for that technique in `data/kihon.json`. If `"image"` is empty, the app looks for `<id>.jpg` named **exactly** as below.

Tips:
- Format: `.jpg`, landscape 4:3 (e.g. 1200 × 900 px), under ~300 KB each so the app stays fast on a phone.
- A plain light background fits the app best; the picture is shown on a warm grey card.
- Using another format or name? Set it in `data/kihon.json`, e.g. `"image": "img/kihon/mae-geri.png"`.
- Only use pictures you made yourself or are allowed to use. The site is public.
